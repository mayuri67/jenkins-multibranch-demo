# Jenkins Multibranch Pipeline Demo

## Project Description

This project demonstrates Jenkins Multibranch Pipeline
using a Python application.

## Project Structure

- app/: Python application
- tests/: Unit tests
- requirements.txt: Python dependencies
- Jenkinsfile: Jenkins pipeline configuration

## Pipeline Stages

1. Checkout source code
2. Install dependencies
3. Run unit tests
4. Build application

## Technologies

- Python
- Pytest
- Jenkins
- Git
- GitHub
